================================================================================
PHYSICS ENGINE DOCUMENTATION: COLLISION DETECTION & IMPULSE RESOLUTION
================================================================================

1. COLLISION DETECTION: SEPARATING AXIS THEOREM (SAT)
--------------------------------------------------------------------------------
For convex 2D shapes (boxes, circles), the engine detects collisions using the 
Separating Axis Theorem:

  "Two convex shapes do not intersect if and only if there exists an axis 
   along which their 1D projections do not overlap."

If an overlap is found across all candidate axes, a collision is occurring. 
The axis with the smallest overlap is chosen as the Collision Normal (OutNormal), 
and that minimum overlap value is the Penetration Depth (OutDepth). Together, 
they form the Minimum Translation Vector (MTV) required to push the shapes apart.

Candidate Axes per Pair:
- Circle vs Circle:
  The line connecting both circle centers (CenterB - CenterA).
  Collision occurs if: Distance(CenterA, CenterB) < RadiusA + RadiusB.

- Box vs Box:
  The 4 face normals of Box A + the 4 face normals of Box B (8 total axes).
  For edge vector E = (x, y), normal axis = (-y, x), normalized to unit length.

- Circle vs Box:
  The 4 face normals of the box + the axis connecting the circle center to the 
  single closest vertex on the box (5 total axes). The closest-vertex axis handles 
  corner impacts where face normals fail.

Projection Math:
- Polygon vertex projection: Proj = Dot(Vertex, Axis).
- Circle projection: CenterProj = Dot(Center, Axis); 
                     Min = CenterProj - Radius; 
                     Max = CenterProj + Radius;


2. POSITIONAL CORRECTION (DEPENETRATION)
--------------------------------------------------------------------------------
Due to discrete time-step integration (DeltaTime), objects can move into each other 
before a collision is detected. To prevent sinking or tunneling, the engine separates 
them immediately along the collision normal:

  BodyA.Position -= OutNormal * (OutDepth * 0.5f);
  BodyB.Position += OutNormal * (OutDepth * 0.5f);

(Assumes equal distribution across both dynamic bodies).


3. VELOCITY RESOLUTION: IMPULSE SCALAR (j) DERIVATION
--------------------------------------------------------------------------------
Newtonian restitution resolves velocities instantly using an impulse vector J.

Definitions:
- OutNormal (n): Unit vector pointing from Body A to Body B.
- Relative Velocity (v_rel): vB - vA.
- e: Coefficient of restitution (0.0 = completely inelastic, 1.0 = elastic).
- mA, mB: Mass of Body A and Body B.
- j: Scalar impulse magnitude.

Step 1: Impulse and Momentum Changes
By Newton's Third Law, equal and opposite impulse J is applied:
  Impulse on B:  +J = +j * n
  Impulse on A:  -J = -j * n

From Delta_Velocity = Impulse / Mass:
  vA' = vA - (j / mA) * n
  vB' = vB + (j / mB) * n

Step 2: Post-Collision Relative Velocity (v_rel')
  v_rel' = vB' - vA'
  v_rel' = (vB + (j / mB) * n) - (vA - (j / mA) * n)
  v_rel' = (vB - vA) + j * (1/mA + 1/mB) * n
  v_rel' = v_rel + j * (1/mA + 1/mB) * n

Step 3: Restitution Law along the Normal
Newton's law states that post-impact separation velocity along the normal is 
proportional to pre-impact closing velocity:
  Dot(v_rel', n) = -e * Dot(v_rel, n)

Step 4: Solving for Scalar j
Take the dot product of both sides of the Step 2 equation with n:
  Dot(v_rel', n) = Dot(v_rel, n) + j * (1/mA + 1/mB) * Dot(n, n)

Since n is a unit vector, Dot(n, n) = 1. Substitute the restitution law:
  -e * Dot(v_rel, n) = Dot(v_rel, n) + j * (1/mA + 1/mB)

Rearrange terms:
  -(1 + e) * Dot(v_rel, n) = j * (1/mA + 1/mB)

Final Impulse Formula:
  j = -(1 + e) * Dot(v_rel, n) / ((1 / mA) + (1 / mB))


4. VELOCITY UPDATE IN CODE
--------------------------------------------------------------------------------
1. Check if bodies are already separating:
     if (Dot(v_rel, OutNormal) > 0.0f) return;

2. Compute scalar impulse j:
     real32 j = -(1.0f + e) * Dot(v_rel, OutNormal);
     j /= (1.0f / A->Mass) + (1.0f / B->Mass);

3. Apply impulse along the normal vector:
     vec2 Impulse = OutNormal * j;
     A->LinearVelocity -= Impulse * (1.0f / A->Mass);
     B->LinearVelocity += Impulse * (1.0f / B->Mass);


5. ENGINE PER-FRAME EXECUTION ORDER
--------------------------------------------------------------------------------
1. ApplyForce:        Velocity += (Force / Mass) * dt
2. RotatePhysicsBody: Rotation += RotationalVelocity * dt
3. MovePhysicsBody:   Position += Velocity * dt
4. Reset Force:       Force = (0, 0)
5. Detect Collisions: SAT checks between all unique pairs (A, B)
6. Depenetrate:       Shift bodies along OutNormal by OutDepth * 0.5f
7. Resolve Velocities:Apply impulse j along OutNormal to both bodies
